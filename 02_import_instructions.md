# Модуль 2. Импорт "Номерной фонд.xlsx" в БД через phpMyAdmin

Файл `Номерной фонд.xlsx` содержит 3 колонки: **Этаж | Номер | Категория**
(категория — текст, например «Одноместный стандарт»).

Наша таблица `Rooms` нормализована: категория хранится не текстом, а ссылкой
`CategoryID` на справочник `RoomCategories`. Поэтому прямой импорт Excel-файла
«в лоб» в `Rooms` не сработает — колонки не совпадают. Делаем в 2 шага: сначала
грузим файл "как есть" во временную таблицу, затем одним SQL-запросом раскладываем
данные по нормализованным таблицам. Это стандартный приём и для реального экзамена
выглядит сильнее, чем просто текстовые категории.

## Шаг 1. Подготовка файла

1. Откройте `Номерной фонд.xlsx` в Excel.
2. «Файл» → «Сохранить как» → тип файла **CSV UTF-8 (разделитель запятая)**.
3. Откройте получившийся `.csv` в Блокноте и посмотрите, какой символ стоит между
   значениями (обычно `,` при сохранении как "CSV UTF-8", но может быть и `;` —
   это важно для шага 3).

## Шаг 2. Временная таблица под структуру Excel

**Важно (проверено на реальном файле заказчика):** колонка «Этаж» в `Номерной фонд.xlsx`
хранит не число, а текст вида `1 этаж`, `2 этаж`, `3 этаж`. Если сделать `Floor INT`
прямо во временной таблице — в одних окружениях импорт тихо превратит `1 этаж` в `1`
(повезёт), а в других (более строгий `sql_mode` в вашем phpMyAdmin) выдаст ошибку
и импорт не пройдёт вообще. Поэтому временную таблицу делаем с `Floor VARCHAR`, а
число достаём отдельным запросом на шаге 4 — так результат не зависит от настроек
конкретного сервера.

Во вкладке SQL базы `alpha_hotel` выполните:

```sql
CREATE TABLE RoomStock_staging (
    Floor        VARCHAR(20) NOT NULL,
    RoomNumber   INT NOT NULL,
    CategoryName VARCHAR(150) NOT NULL
);
```

## Шаг 3. Импорт CSV во временную таблицу

1. Выберите таблицу `RoomStock_staging` → вкладка **Импорт**.
2. Выберите файл `.csv`.
3. Формат — CSV.
4. "Строка с именами столбцов не должна содержать данные" → если в файле есть
   заголовок (Этаж/Номер/Категория) — поставьте пропуск **1** строки, иначе **0**.
5. Разделитель столбцов — тот символ, что вы увидели в Блокноте (`,` или `;`).
6. Нажмите «Вперёд»/«Импорт».

**Ещё один проверенный нюанс:** при сохранении как "CSV UTF-8" Excel добавляет в
самое начало файла невидимый символ (BOM), который может испортить первое же
значение файла. Пока в файле остаётся строка заголовков и вы указываете "пропуск
1 строки" (как в пункте 4) — порченным окажется заголовок, а не реальные данные,
и это неопасно. А вот если вы зачем-то удалите строку заголовков и укажете пропуск
0 строк — испортится именно первая строка с номером 101 (её «Этаж» превратится в 0).
Поэтому: заголовок в файле лучше не трогать.

## Шаг 4. Перекладываем данные в нормализованные таблицы

Категории в файле уже совпадают с теми, что мы занесли в `RoomCategories` в
`02_create_database.sql`. Статус по умолчанию при первичной загрузке — «Свободен»
(2 — это StatusID «Свободен», см. порядок INSERT в `02_create_database.sql`).

```sql
INSERT INTO Rooms (Floor, RoomNumber, CategoryID, StatusID)
SELECT
    CAST(SUBSTRING_INDEX(s.Floor, ' ', 1) AS UNSIGNED),  -- "1 этаж" -> 1
    s.RoomNumber,
    c.CategoryID,
    (SELECT StatusID FROM RoomStatuses WHERE StatusName = 'Свободен')
FROM RoomStock_staging s
JOIN RoomCategories c ON c.CategoryName = s.CategoryName;
```

Проверьте результат:

```sql
SELECT r.RoomID, r.Floor, r.RoomNumber, c.CategoryName, st.StatusName
FROM Rooms r
JOIN RoomCategories c ON c.CategoryID = r.CategoryID
JOIN RoomStatuses st ON st.StatusID = r.StatusID
ORDER BY r.Floor, r.RoomNumber;
```

Должно получиться 26 номеров (столько строк в `Номерной фонд.xlsx`).

## Шаг 5 (по желанию). Актуализация статусов

Если успеете — можно так же импортировать `Отчет по состоянию номерного фонда на дату.xlsx`
во вторую staging-таблицу и обновить `Rooms.StatusID` реальными статусами (Занят/Чистый/
Грязный/Назначен к уборке) через `UPDATE ... JOIN`. Для сдачи базового варианта модуля 2
это не обязательно — задание прямо требует импортировать только «Номерной фонд.xlsx».

## Автоинкремент (A_I)

Если создаёте таблицы вручную через визуальный конструктор phpMyAdmin (не SQL-вкладкой),
не забудьте у ключевого поля (`RoomID`, `OrderID` и т.д.) поставить галочку **A_I**
(auto increment) — это и есть автоинкремент из задания.
