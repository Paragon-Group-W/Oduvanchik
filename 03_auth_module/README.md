# Модуль 3. Проектная документация: авторизация и управление пользователями

## Назначение

Веб-модуль обеспечивает вход сотрудников гостиницы Alpha в систему с проверкой
логина/пароля, разграничение по ролям «Администратор»/«Пользователь», принудительную
смену пароля при первом входе и автоматическую блокировку учётной записи при подборе
пароля или длительном отсутствии активности.

## Установка (с нуля, по шагам)

1. Установите и запустите **OpenServer** (если ещё не стоит).
2. В настройках OpenServer включите модуль **MySQL** — без этого ничего работать не будет.
3. ПКМ по значку OpenServer в трее → **Домены** → создайте новый домен, например
   `alpha-hotel`. Это создаст папку сайта, обычно
   `OpenServer\domains\alpha-hotel\`.
4. Скопируйте **всё содержимое** папки `03_auth_module` (все `.php` файлы и `styles.css`)
   прямо в корень этой папки домена.
5. ПКМ по значку OpenServer → **Дополнительно** → **PhpMyAdmin** (откроется в браузере).
   Во вкладке SQL вставьте и выполните содержимое `02_create_database.sql` (создаёт БД
   и таблицы, в т.ч. `Users`/`Roles`).
6. При необходимости поправьте `db.php` (хост/логин/пароль MySQL — по умолчанию
   `localhost` / `root` / пустой пароль, обычно для OpenServer подходит как есть).
7. В браузере откройте `http://alpha-hotel/setup_admin.php` (вместо `alpha-hotel` —
   имя вашего домена) один раз — создаст пользователя `admin` / `admin123` с
   принудительной сменой пароля при первом входе.
8. Откройте `http://alpha-hotel/login.php` — это и есть рабочая форма входа.

## Файлы и их функциональное назначение

| Файл | Назначение | Основные параметры/методы |
|---|---|---|
| `db.php` | Подключение к MySQL | `getConnection(): mysqli` — возвращает единое соединение (паттерн одиночка через `static`) |
| `login.php` | Форма входа, проверка логина/пароля, учёт неудачных попыток, ленивая блокировка по неактивности | Обрабатывает `$_POST['username']`, `$_POST['password']` |
| `change_password.php` | Принудительная смена пароля при первом входе (`PasswordChanged = 0`) | `$_POST['current_password']`, `$_POST['new_password']`, `$_POST['confirm_password']` |
| `dashboard.php` | Стартовая страница после входа, показывает роль и ссылку на админку | — |
| `admin_users.php` | Список пользователей, добавление нового, разблокировка — только для роли «Администратор» | Действия `add_user` (параметры: `new_username`, `new_user_password`, `new_role`), `unblock` (параметр `user_id`) |
| `logout.php` | Завершение сессии | — |
| `setup_admin.php` | Одноразовое создание первого администратора с корректным хэшем пароля | — |
| `reset_password.php` | Аварийный сброс пароля/блокировки, если заблокировался сам и зайти больше некем | `?username=...&new_password=...` в адресной строке |

## Правила, реализованные по тексту задания

- Поля «Логин» и «Пароль» обязательны — проверка на пустую строку перед обращением к БД.
- Неверный логин/пароль → `"Вы ввели неверный логин или пароль. Пожалуйста проверьте ещё раз введенные данные"`.
- Успешный вход → `"Вы успешно авторизовались"`.
- 3 неверные попытки подряд (`FailedAttempts` в таблице `Users`) → `Blocked = 1`,
  далее при любой попытке входа → `"Вы заблокированы. Обратитесь к администратору."`.
- Если `LastLoginDate` старше 30 дней на момент попытки входа — учётная запись
  блокируется автоматически (проверяется в `login.php` до сверки пароля).
- При `PasswordChanged = 0` после успешного ввода пароля пользователь принудительно
  попадает на `change_password.php`, минуя рабочий стол.
- Добавление пользователя с уже существующим логином → `"Пользователь с таким логином уже существует."`.
- Пароли никогда не хранятся в открытом виде — только `password_hash()`/`password_verify()`.

## Как проверить (сценарии для самопроверки перед экзаменом)

1. **Первый вход администратора**: `admin` / `admin123` → должно сразу перебросить
   на смену пароля → после смены → `"Вы успешно авторизовались"` на дашборде.
2. **Неверный пароль**: 2 раза подряд неверный пароль у существующего пользователя →
   на 3-й раз должно появиться сообщение о блокировке, а не "неверный логин/пароль".
3. **Разблокировка**: зайдите под администратором → `admin_users.php` → у
   заблокированного пользователя нажмите «Разблокировать» → попытка входа снова
   должна давать 3 новые попытки.
4. **Дубликат логина**: попробуйте создать пользователя с уже существующим логином →
   должно появиться сообщение о дубликате, запись не создаётся.
5. **Блокировка по неактивности**: вручную в phpMyAdmin поставьте пользователю
   `LastLoginDate` на дату более 30 дней назад → следующая попытка входа (даже с
   верным паролем) должна завершиться сообщением о блокировке.

## Если сам заблокировался и зайти некем (важно для экзамена)

Если единственный администратор заблокирован (3 неверные попытки) — через саму форму
входа разблокировать некого, нужна БД или `reset_password.php`.

**Просто снять блокировку (пароль помните) — в phpMyAdmin, вкладка SQL:**
```sql
UPDATE Users SET Blocked = 0, FailedAttempts = 0 WHERE UserName = 'admin';
```

**Забыли и пароль — через браузер:**
```
http://alpha-hotel/reset_password.php?username=admin&new_password=новый_пароль
```
Снимает блокировку, сбрасывает счётчик попыток и ставит новый пароль (при следующем
входе система попросит сменить его ещё раз, как при самом первом запуске).
