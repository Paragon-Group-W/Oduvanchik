# Решение демоэкзамена КОД 09.02.07-5-2025 («Гостиница Alpha»)

Это разбор настоящего задания, найденного внутри архива `пробный вариант задания ДЭ.7z`
из репозитория `TOXAceleron/demo-exam-spec-po-info-system`. В самом GitHub-репозитории
лежал только частичный пример (ER-диаграмма + SQL), а в архиве — официальный текст
задания (КОД 09.02.07-5-2025, стр. 27-30), брифинг заказчика и реальные Excel-данные
гостиницы.

## Важно: тут нет "одного PHP-проекта"

Экзамен состоит из **3 модулей**, и они используют разные инструменты:

| Модуль | Что делать | Чем делать |
|---|---|---|
| 1. Проектирование ИС | Нарисовать ER-диаграмму (3НФ) | MS Visio / любой ER-инструмент → экспорт в `.pdf` |
| 2. Администрирование БД | Создать БД, импортировать Excel, написать SQL-запрос | MySQL через **phpMyAdmin** (вот откуда в задании "PHP" — это просто веб-панель администрирования СУБД, а не язык вашего приложения) |
| 3. Разработка ИС | Форма входа, роли, блокировки, админка пользователей | Веб-приложение на **PHP** (выбрано как самое быстрое продолжение связки MySQL/phpMyAdmin — см. файл `03_auth_module`) |

Если в колледже вас учили другому языку для модуля 3 (C#, Java и т.п.) — вся *логика*
(тексты сообщений, правила блокировки, SQL-запросы) one-to-one переносится в любой
стек, меняется только синтаксис самих файлов в `03_auth_module/`.

## Что брать с собой / что сдавать

1. `01_ER-diagram.pdf` — готовый файл для сдачи Модуля 1 (таблицы, атрибуты, PK/FK,
   связи 1:N — именно это требует текст задания; Visio строго не нужен, т.к. задание
   требует именно `.pdf`, а не конкретный формат файла-источника). Рядом есть
   `01_ER-diagram.vsdx` — та же схема в формате настоящего Visio-файла (собран без
   самого Visio, проверен независимо через LibreOffice — подробности и предостережение
   в `01_ER-diagram.md`). `01_ER-diagram.md` — то же самое текстом/Mermaid, с
   объяснением, откуда взялась каждая сущность и почему это 3НФ.
2. `02_create_database.sql` + `02_import_instructions.md` — всё для Модуля 2:
   создание БД и таблиц, импорт `Номерной фонд.xlsx`.
3. `03_occupancy_query.sql` — SQL-запрос «процент загрузки номерного фонда» для Модуля 2.
4. `03_auth_module/` — готовый PHP-код для Модуля 3 (логин, роли, блокировки, админка)
   + `README.md` внутри — краткая проектная документация, которую тоже требует задание.

## Порядок действий на экзамене

1. Откройте `01_ER-diagram.md`, сверьте/перерисуйте диаграмму под ваш реальный брифинг
   (данные могут немного отличаться от варианта, который разобран здесь).
2. Выполните `02_create_database.sql` в phpMyAdmin → вкладка SQL вашей новой БД.
3. Импортируйте `Номерной фонд.xlsx` по инструкции `02_import_instructions.md`.
4. Проверьте `03_occupancy_query.sql`.
5. Скопируйте `03_auth_module/*.php` в папку сайта OpenServer, поправьте в `db.php`
   имя БД/логин/пароль, прогоните сценарии из `03_auth_module/README.md`.
